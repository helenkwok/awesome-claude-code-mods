office

A Claude Code mod in adamentwistle/claude-code-mods

A pixel-art office of your running Claude Code sessions: one desk per session, animated by what it is doing, with speech bubbles, layouts, characters and drag to arrange. Uses herdr when present, Claude Code's own session records otherwise.
