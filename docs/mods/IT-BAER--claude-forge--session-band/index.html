session-band

A Claude Code mod in IT-BAER/claude-forge

Prompt cache status band (c / ctx / rwc / sc / plan limits) with hover help, cold-send guard, keep-warm, board and a handoff that also picks up handoff files (all under /session-band), and an autonomous mode that clears and continues each handoff. Fork of Cache Keeper by Nate Herk.

Access

L1 Reads filesreads the transcript, persists state, draws

Passed with warnings on Claude Code 2.1.332
